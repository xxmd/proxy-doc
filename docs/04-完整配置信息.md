## 七、换机 / 重装恢复步骤

```bash
# 1. 新机器装依赖
apt-get update -qq && apt-get install -y -qq unzip

# 2. 装 Xray —— 必须锁 v26.6.27，装 latest 会让 Clash Verge(mihomo) 握手失败
curl -fsSL -o /tmp/xray-install.sh https://github.com/XTLS/Xray-install/raw/main/install-release.sh
bash /tmp/xray-install.sh install                    # 先按官方脚本装好 systemd/目录
curl -fsSL -o /tmp/x.zip \
  https://github.com/XTLS/Xray-core/releases/download/v26.6.27/Xray-linux-64.zip
unzip -oq /tmp/x.zip -d /tmp/xr26627
install -m 0755 /tmp/xr26627/xray /usr/local/bin/xray
xray version | head -1                                # 应显示 Xray 26.6.27

# 3. 上传本仓库的配置与脚本
scp server/xray-config.json server/*.sh root@<新IP>:/tmp/

# 4. 部署（装配置 + BBR + systemd 资源路径 + 日志权限）
ssh root@<新IP> "bash /tmp/xray-setup.sh /tmp/xray-config.json"

# 5. 全链路验证（注意：这一步用的是 Xray 自家客户端，它能通不代表 mihomo 能通）
ssh root@<新IP> "bash /tmp/xray-verify.sh"

# 6. 真正要验的是客户端：用 mihomo/Clash Verge 连一次，能出 204 才算成
```

> 若要**生成新密钥**（例如怀疑已泄露）：`xray x25519` 得到新的私钥/公钥，替换
> `server/xray-config.json` 的 `privateKey` 和 `client/clash-hk.yaml` 的 `public-key`，两边同时改，然后重启 xray。

然后在客户端把 `clash-hk.yaml` 里的 `server` 换成新 IP 即可。
